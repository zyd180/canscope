# CANScope 用户手册

## 快速开始

1. 运行 `CANScope.exe`。
2. 点击“打开文件…”选择日志文件和对应的 DBC。
3. 在左侧报文树点击信号，示波器会显示曲线。
4. 使用工具栏“导出 CSV”或“导出片段 BLF”保存分析结果。

## 支持格式

- 日志：BLF、ASC、MF4/MDF4。
- 数据库：DBC，支持 UTF-8、GBK 和 GB18030。
- MF4 需要安装可选依赖 `asammdf`。

## 快捷键

| 操作 | 快捷键 |
|---|---|
| 打开文件 | `Ctrl+O` |
| 缩放时间轴 | 鼠标滚轮 |
| 滚动示波器页面 | `Shift+滚轮` |
| 平移时间轴 | 左键拖拽 |
| 区间统计 | `Ctrl+左键拖拽` |
| 测量锚点 | `Shift+单击` |
| 自动/锁定 Y 轴 | 双击绘图区 |

## 配置与导出

- “配置”可修改总线类型、波特率、通道 DBC 映射和抖动标记。
- “自动适配 DBC…”会根据每个通道的报文 ID 与 DLC 匹配候选 DBC。
- 右键示波器可重置缩放、锁定 Y 轴、导出 PNG 和清除信号。
- Trace 页支持分页查看、信号值过滤和全量 CSV 导出。

## 故障排查

- 启动或后台任务异常时，检查应用目录下的 `logs/crash.log`。
- 打包版本可运行 `CANScope.exe --smoke` 检查演示数据、解码和界面启动。
